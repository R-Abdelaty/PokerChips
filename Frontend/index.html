PokerChips

Free Online Poker Chip Counter

Replace physical poker chips with a simple digital counter built for friendly home games. Set up 2–6 players, choose a starting balance, and track every check, call, raise, fold, and win without using real money.

Quick setup

How PokerChips works

  1. 01

    Set up the table

    Choose between 2 and 6 players, enter their names, and select a starting chip balance.

  2. 02

    Play each hand

    Use the table controls to check, call, raise, fold, and undo an accidental action.

  3. 03

    Award the pot

Common questions

PokerChips FAQ

Is PokerChips free?

Yes. PokerChips is a free browser-based chip counter for casual home poker games.

Does PokerChips involve real money?

No. The app tracks virtual chip balances and is designed as a replacement for physical chips.

How many people can play?

You can create a table for 2, 3, 4, 5, or 6 players.

Do players need to install an app?

No. PokerChips runs directly in a modern web browser and can also be added to a device home screen.
